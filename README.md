# 🧮 Python Function – Basic Math

A collection of Python programs for practicing **functions, conditional statements, and basic mathematical problem-solving**.

## 📚 Programs

1. `basic_salary.py` — Calculate salary based on basic salary
2. `electricity_bill.py` — Calculate electricity bill based on units
3. `even_odd.py` — Check whether a number is even or odd
4. `grade.py` — Calculate grade from marks
5. `maximum_3_number.py` — Find the maximum among three numbers
6. `minimum_3_number.py` — Find the minimum among three numbers
7. `profit_loss.py` — Calculate profit or loss

## 🎯 Goal

To strengthen **Python fundamentals, logical thinking, and mathematical problem-solving** using functions.
